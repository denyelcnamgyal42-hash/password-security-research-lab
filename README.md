# Password Security Research Lab

A cybersecurity research project evaluating password security, hashing algorithms, and password policies using controlled synthetic datasets.

## Goals

- Compare password hashing algorithms
- Analyze password cracking resistance
- Study effects of salts
- Evaluate password policies
- Generate security recommendations


## Technologies

Python | Hashcat | John the Ripper | bcrypt | Argon2id


## Ethical Notice

This project is performed only with synthetic data inside a controlled laboratory environment.
